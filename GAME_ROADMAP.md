# Darkfall RPG.io — Development Roadmap

## Current direction
HTML5 top-down dark-fantasy RPG.io built with React, TypeScript, Vite and a custom Canvas game engine.

## Core gameplay
- Large top-down world with zones and bosses
- Character classes and active skills
- XP, levels and stat progression
- Inventory and equipment
- Loot rarity progression
- Quests and rewards
- Minimap/radar
- Mobile touch controls
- PvE first, multiplayer later

## Monster progression
- Levels 1-10: basic melee monsters without weapons
- Level 11+: armed monsters and more dangerous attack patterns
- Show attack/range danger indicators for armed monsters
- Stronger monsters use darker visual treatment
- Bosses and valuable loot should be visible on radar/minimap

## Equipment
- Weapon, armor and accessory slots
- Item rarity becomes visually darker/richer at higher tiers
- Full armor sets can grant set bonuses
- Weapons need visible attack animations

## Classes
Each class should have at least 3 active skills plus a basic attack and class identity.

## UI
Dark fantasy / classic MMORPG direction with bronze-gold metal, dark panels and readable combat information.

## Next implementation milestones
1. Lock monster level/range progression.
2. Improve combat telegraphs and weapon animation readability.
3. Expand equipment and set bonuses.
4. Improve world art and zone identity.
5. Add save progression.
6. Add real multiplayer/server layer after the single-player loop is stable.
